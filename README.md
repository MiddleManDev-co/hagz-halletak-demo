# Hagz Halletak — حجز هالتك

Static responsive concept landing page for an Egyptian event-tech platform focused on:

- Real-time venue availability
- Venue search and booking
- Verified venue information
- Venue-management SaaS / calendar operations

## Run locally

Open `index.html` directly in a browser.

No build step and no JavaScript framework are required.

## Deploy

Deployment is handled automatically through:

`.github/workflows/pages.yml`

Every push to `main` triggers a GitHub Pages deployment.

Live URL:

`https://middlemandev-co.github.io/hagz-halletak-demo/`

## Stack

- Semantic HTML5
- Vanilla CSS
- Small vanilla JavaScript interactions
- Arabic-first RTL responsive design
